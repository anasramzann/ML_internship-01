# Portfolio Identity Kit — FlyRank Search Intelligence Track

A minimal, intentional visual identity system designed to frame ML research, data contracts, and search metrics without visual distractions.

---

## 1. Typography Selection

* **Heading & Body Font:** `Inter` (Google Font)  
  *Clean, highly readable sans-serif typeface designed for user interfaces and analytical case studies.*
* **Code & Metrics Font:** `JetBrains Mono` (Google Font)  
  *Applied to SQL queries, Python code blocks, pandas DataFrames, and precision scores (`Precision@20`).*

---

## 2. Color Palette (4-Color Constraint)

| Element | Color Name | Hex Code | Purpose |
|---|---|---|---|
| **Background** | Near-White Slate | `#F8FAFC` | High-contrast, clean base layer that eliminates eye strain. |
| **Primary Text** | Deep Slate Black | `#0F172A` | Crisp typography readability for long-form case studies. |
| **Secondary / UI** | Slate Grey | `#334155` | Subtle borders, table header fills, and secondary labels. |
| **Accent Color** | Signal Blue | `#2563EB` | Used sparingly for key links, active tabs, and target metrics. |
